# AAPD — 心情追蹤（心情日誌）

一隻溫柔的熊，陪你記錄每天的心情。AAPD 是一款使用 React + Vite + Tailwind CSS 打造的心情追蹤應用程式，幫助你透過每日紀錄、行事曆回顧與智慧洞察，持續關注自己的情緒健康。

## 功能介紹

### 🏠 首頁
- **個人化問候** — 顯示今日日期與星期
- **互動式心情圈** — 點擊動畫圓環開啟心情記錄流程；載入時展現漸層揭露效果
- 底部功能表列切換各個頁面

### 🌈 心情記錄
多步驟底部彈出式面板，支援拖曳關閉：
1. **心情滑桿** — 7 段色彩光谱，從「非常緊繃」到「非常愉快」，中間加入中性「普通」選項。小熊圖案會隨著你的滑動即時變色。
2. **標籤選擇** — 從三大類別中挑選：身心狀態、人際關係、外在現實
3. **確認送出** — 一頁回顧你選的心情與標籤，再以動畫完成儲存

### 📅 回顧頁面
三種分頁查看心情紀錄：
- **月** — 完整行事曆网格，每天顯示小熊心情圖示；可點擊空白日期提醒記錄、過去／未來日期以不同樣式呈現
- **週** — 色彩條一目了然顯示整週情緒形狀；列出已記錄的項目，支援刪除與復原
- **日** — 單日詳細檢視：心情熊、選取的標籤、個人備註

### 🐻 問熊熊（智慧洞察）
與熊熊小熊聊天的介面，它會根據你的心情資料回答問題：
- 「這週心情怎麼樣？」— 整週心情摘要與平均情緒標籤
- 「這個月最常出現的情緒是？」— 本月主導情緒分析
- 「什麼最常影響我的心情？」— 最常出現的標籤排名
- 「這個月我記錄了幾天？」— 本月紀錄頻率統計
- 支援自由輸入，以關鍵字匹配進行回答

### ⚙️ 設定頁面
- 個人資料展示（頭像、電子郵件）
- 通知偏好開關
- 安全性設定（密碼鎖、Face ID）
- 變更密碼與登出功能

## 色彩系統

應用程式使用 6 段 pastel 色彩對應不同情緒值：

| 數值 | 色彩 | 情緒 |
|-------|-------|------|
| 0 | `#BAAFD6` | 非常緊繃 |
| 20 | `#66CCED` | 緊繃 |
| 40 | `#92D0A8` | 平靜 |
| 60 | `#FACA78` | 愉快 |
| 80 | `#F6B386` | 開心 |
| 100 | `#F3A9B7` | 非常愉快 |

色彩系統透過 HSL 轉換自動衍生更深的線條與文字色調，確保整套配色對比一致。
